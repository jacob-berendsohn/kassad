# Evaluation

A guardrail without published numbers is a toy. This directory holds the harness that produces the
table in the root README.

- `Kassad.Eval/` — console app. See `Program.cs` for the CLI contract.
- `datasets/` — download scripts and label adapters, one per dataset. Raw data lands in `data/` (git-ignored).
- `results/` — dated JSON outputs. Committed, so the README table is reproducible.

## Datasets (planned)

| Dataset | Stage | What it measures |
|---|---|---|
| JailbreakBench | inbound | jailbreak / injection detection |
| deepset prompt-injections | inbound | injection detection, benign vs. malicious |
| ToxicChat | inbound + outbound | toxicity, unsafe requests |
| A grounding set (TBD in roadmap 4.3) | grounding | claim ↔ source support |

## What we report

Per policy, per threshold: precision, recall, F1. Plus ROC AUC, a calibration plot (predicted vs.
observed), p50/p95 model latency, and cost per 1k checks at TypeSafe's published pricing.

Numbers are regenerated by CI on a schedule and on tag. Hand-edited numbers in the README are a bug.
